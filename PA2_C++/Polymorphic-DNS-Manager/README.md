Polymorphic DNS Manager

The task tests students on runtime polymorphic classes, deep copying, recursive string parsing, recursive tree traversal, and linked lists.

My program simulates various classes such as CZone (container of DNS records) and various DNS record types (CRecA, CRecAAAA, CRecMX, CRecSPF, CRecCNAME - each with its own challenges). CZone itself can also be contained in another CZone (subzone). It can add, delete, search, and copy the polymorphic records.
