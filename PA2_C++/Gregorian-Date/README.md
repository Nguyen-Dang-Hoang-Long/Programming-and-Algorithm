Gregorian Date

The program simply implements a class that represents a date.

It also include some methods:
- Operator +, - : Shifts the date to the future or the past (with a positive or a negative integer of days).
- Operator -: Subtract two dates and return the difference in days between them (integer)
- Operator ++, --: Increase/Decrease the date by one day
- Operator ==, !=. <, >, <=, >=: Compare 2 dates
- Operator <<, >>: Display/Read the date
