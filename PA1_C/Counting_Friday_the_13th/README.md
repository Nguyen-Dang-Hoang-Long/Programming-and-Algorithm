Counting_Friday_the_13th

In this program, I only develop 3 functions with following usages:

countFriday13 (from, to, cnt)
Given 2 dates (from, to) and an output parameter (cnt), the function counts the number of Friday the 13th between the 2 dates and saves in into the output parameter, then return true or false (invalid input)

prevFriday13 ( x )
Given date x, the function finds the closest Friday the 13th that precedes x. The date of the found Friday the 13th is stored into x, then the function returns true or false.

nextFriday13 ( x )
Given date x, the function finds the closest Friday the 13th that follows x. The date is stored into x, then the function returns true or false.
